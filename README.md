# Viraró Bodegón — Landing profesional

Landing HTML + CSS para **Viraró Bodegón Parrilla**, Sarmiento 1334, CABA.

## Incluye

- HTML semántico y responsive, sin framework.
- SEO técnico base: `title`, meta description, canonical, Open Graph, jerarquía de headings, atributos `alt` y enlaces internos/externos claros.
- Datos estructurados Schema.org para `Restaurant` y `FAQPage`.
- Propuesta de valor: comida casera y abundante a precios accesibles.
- Valoración pública atribuida a TodoResto: 3,9/5 sobre 1.362 opiniones. No se inventaron testimonios.
- Botón flotante de WhatsApp con Font Awesome 7.3.1 hacia `https://wa.me/5491138833144`.
- Imágenes oficiales copiadas en `img/` desde el sitio de Viraró.

## Archivos

- `index.html`: estructura, contenido y Schema.org.
- `styles.css`: sistema visual responsive.
- `img/`: logo y fotografías oficiales.
- `brand-spec.md`: inventario y fuentes de assets.
